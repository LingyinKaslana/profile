# 从隐式到显式：面向手物交互生成的动力学建模方法

> 把力、力矩和几何接触线索显式注入扩散框架。

**类型** 论文 · **角色** 第一作者 · **状态** AAAI 2027 在投 · **时间** 2026

[← 返回首页](../../README.md)

## 挑战

隐式建模难以把物体运动、接触行为与手部关节关联起来，生成结果在物理上不成立。

## 做法

- 将 HOI 相关的物理信息作为可学习信号显式注入潜在扩散框架
- 以估计的力与力矩作为显式输入 / 输出通道，与运动潜变量联合去噪
- 由关节-物体最小距离构造 affordance map 作为几何接触线索，指导手部姿态调制与推理期精修

## 结果

- 在 GRAB 与 OakInk 上显著优于基线
- 展现出强跨数据集泛化能力

## 关键数字

| 指标 | 数值 |
| :-- | :-- |
| 评测数据集 | GRAB、OakInk |
| 显式信号 | 力 / 力矩、affordance map |
